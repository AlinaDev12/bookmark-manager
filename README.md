# Bookmark Manager

Bookmark Manager is a MERN Stack web application that helps users save, organize, search, and manage their favorite website links.

## Features
- Add new bookmarks
- View all saved bookmarks
- Search bookmarks
- Filter bookmarks by tags
- Mark and unmark favorite bookmarks
- View favorite bookmarks
- Delete bookmarks
- Open saved links in a new tab

## Technologies Used
- MongoDB
- Express.js
- React.js
- Node.js
- Axios
- CSS

## Project Structure
- `backend/` – Backend API and database connection
- `frontend/` – React frontend application

## Installation and Setup

### Backend
1. Open the backend folder.
2. Run `npm install`.
3. Create a `.env` file with your MongoDB connection string.
4. Run `node server.js`.

### Frontend
1. Open the frontend folder.
2. Run `npm install`.
3. Run `npm run dev`.
